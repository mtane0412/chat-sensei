# chat-sensei

Twitch のライブチャットを **生IRC / 翻訳 / Pick up** の3カラムで読む、サーバーを持たないクライアントサイド専用の語学学習ツールです。

- 左列: 匿名接続した Twitch IRC の発言をそのまま表示します(表示名の色・emote画像付き)
- 中央列: 発言ごとの翻訳を左列と同じ行に表示します(受信した発言を自動で全件翻訳。追いつかない分は「未翻訳」と明示)
- 右列: 発言ごとに注目の表現(スラング・略語・イディオム・ミーム)を抜き出し、語句と短い意味のペアを同じ行に表示します(翻訳と同様に自動で全件処理。追いつかない分は「未抽出」と明示)
- 翻訳列・Pick up列は初期状態では見えており、各列見出しの目のアイコンでぼかせます(まず自力で読み、答え合わせに使いたいときに利用)
- 生IRC列の見出しにある追従トグル(初期状態はオン)で、新着発言に合わせてチャット欄を自動で最下部へスクロールし続けます(上へスクロールして読み返し始めると自動でオフになります)
- 生IRC列の見出しにある bot除外設定から、bot のユーザー名を指定してチャット欄から除外できます(`*trans` のような `*` ワイルドカード対応。Nightbot / StreamElements など著名な bot は初期状態で除外)
- 生IRC列の見出しから学ぶ言語(翻訳・Pick up の対象にするチャットの原文の言語。複数選択可)、翻訳列の見出しから解説言語(翻訳・Pick up の意味の言語)を en / ja / es / de / fr で選べます(初期値は学ぶ言語 = en、解説言語 = ja。変更すると表示中の発言の翻訳・Pick up を新しい設定で生成し直します)。言語は配信ごとに異なるため、アプリ全体の設定ではなく各列から切り替えます
- 発言ごとに Chrome 内蔵の Language Detector API で言語を判定し、学ぶ言語の発言だけを翻訳・Pick up します。解説言語と同じ言語の発言は「Same language」、学ぶ言語以外の発言は「Not a learning language (言語コード)」と表示して処理しません。ひらがな・カタカナ(半角含む)を含む発言は判定結果によらず日本語とみなし、漢字だけの発言(太陽神 など)が zh と判定された場合も日本語が設定にあれば日本語とみなします(このアプリでは中国語を選べないため)。絵文字・emote・記号だけの発言は判定せずそのまま表示します。12 文字以下の Latin 文字だけの発言(KEKW など)で判定が定まらない場合は、学ぶ言語のうち Latin 文字の先頭言語で扱います。短い感嘆詞(oooohhh ok など)や漢字だけの発言(人気投票 など)で最上位候補が無関係な言語になった場合は、候補列に十分な信頼度の学ぶ言語・解説言語があればそれを採用します(英語と日本語が混ざるチャットで、日本語の発言を訳さない、といった使い方ができます)
- 接続フォーム横の設定(歯車アイコン)から、Prompt API / Language Detector API の環境診断(Chrome バージョン・モデルの利用可否・ストレージ)の確認と設定の初期化ができます

AI推論は Chrome 内蔵の Gemini Nano(Prompt API)と Language Detector API でブラウザ内に完結し、ログイン・バックエンド・外部APIキーは不要です。

> 現在はコンセプト刷新直後で、単語帳などの周辺機能は未実装です。

## 開発

```bash
npm install
npm run dev         # http://localhost:3000
npm test            # Vitest
npm run lint
npm run type-check
```
